## 0. 全局口径（50 条序列共同遵守）

| 项 | 规定 |
|---|---|
| 演示数据声明 | **本规范所有数值均为「原型演示数据（非真实健康测量）」**，用于确定性重绘截图对应图表；不得冒充 Apple HealthKit / SwiftData 实测值，不得写入 `Healthy/` 的真实数据链路。统一措辞：「原型演示数据（非真实健康测量）」。 |
| 与 App 的关系 | `Healthy/` 用真实 HealthKit / SwiftData 数据链路，App 侧复用**同名字段口径**（metric / unit / range / granularity / missing）但取真实数据源；来源角标必须区分「原型演示数据」与「Apple 健康」。原型演示数据禁止反向写入 App。 |
| 来源角标模板 | `数据来自 {来源} · 更新于 {时间}`，**落 DOM**（`<p class="source-note">`），不写进 SVG。`{来源}` 只允许两种填法：`原型演示数据`（逐点序列由 Phase 2 依据可见锚点构造，默认，绝大多数）、`截图可见值`（整条序列/段值/次数以页面可见文字直接给出，如 capsule 58/22/14/6、stack 13/32/55、ring/disc 读数）。 |
| `{时间}` 填法 | 取页面可见更新时间，禁止编造：`2026-11-07 10:05`（今日/详情/sheet，可见「数据更新于 10:05」+ 报告日）、`2026-11-07`（日报告/健康页，可见 2026年11月7日）、`2026-11-08`（趋势周，可见 11月2日-11月8日 截止）、`2026-11-07`（睡眠月，可见 11月1日-11月30日，演示数据截止 11/07）、`2026-11-07（每日凌晨更新）`（身体年龄，可见「每日凌晨更新数据 · 2026年11月7日」）、`2026-11-06`（VO2，可见「11月6日 周五」）、`2026-11-07`（洞察，可见「过去 60 天」窗口截止）。 |
| 对比度硬约束 | 单位 / 口径 / 来源文字 **≥11.5px 且 `--ink-2 #5C6268`（6.17:1）**；**8.5px `#9BA1A7` 只能做坐标轴刻度**；四档状态色（绿 `#79C98E` / 紫 `#8D90E4` / 橙 `#F79B62` / 粉 `#EE6E88`）**禁止直接当文字色**；图例最多 3 项，超出改用 sheet。 |
| 点数 = 粒度 | **采样点数 = x 轴时间粒度**：每点 = 1 日 / 1 小时 / 1 次采样，必须在 `xAxis.granularity` 写明。3 个可见标签只是首/中/末**时间锚点**，不是逐点标签；若标签数 ≠ 点数，须在 `labelNote` / `caliber` 解释，不得留歧义。 |
| 缺失值 | JSON 中**统一用 `null`** 表示无采样（`points` 长度仍等于采样点数）；落 DOM 时转 `0` + `--faint`（柱高 0 / `#E9EAEE` 空点）+ aria「无数据」；**真实 0 值与缺失必须区分**（如「压力过载 0 天」是真实 0，不是无数据）。唯一例外：`chartKind=dots` 点阵用分类编码 `0` 表示「无采样空点」（编码非测量值）。禁止留白、红色问号、用 0 冒充已采集。 |
| 14 类图表 | `line / area / bars / hist / step / dots / ring / disc / stack / capsule / spark / wave / dualbars / mini`（与 `charts.mjs` RENDERERS 一一对应）；本规范覆盖 `screens/*.html` 49 处 + `sheets.html` 1 处 = **50 处实例**。 |
| 数值锚点 | 页面可见文字/柱高/刻度为硬锚点：今日平均 HRV 40ms / 近期平均 30ms、静息心率近期平均 69bpm、HRV 基线 30.7ms、身体年龄 34.2 岁「多5.9岁」、衰老速度 -0.2x、VO2 平均 38 / 范围 28–67、睡眠 11/1–7 时长均值 6.15h / 质量均值 75 / 连续性均值 79 / 有效睡眠占比均值 96 / 恢复性睡眠 2.6h、趋势周 02–08 日、睡眠时段 02:47–07:42。**每条序列的均值 / 末点 / 极值已逐条与这些锚点对齐**。 |
| 已裁决项 | 本文 §4 的 **Q5 / Q19 / Q20 / Q21 已由 01 §9 R1 正式裁决**，不再是待确认项：来源角标以 ≥11.5px / `--ink-2` 为准（§5.4 旧字号废止）；disc 中心 13/39/11px SVG 文字保留但口径唯一载体为 DOM 副本；01 §4.4 退出数据语义；深色模式原型侧不启用、manifest 记 `darkVariant: reserved`。本文其余章节已按裁决同步。 |

## 6. 给 Phase 3 的落地约束（简洁）

1. **manifest 必含字段**：`id / kind / origin / scenario / alt / viewBox / palette / source / units / range / dataset`（+ `page / trigger / dark / caption`）。`origin` 语义值 `replica|stylized` → DOM `data-origin` 字面值 `screenshot|stylized`，构建期统一转换；`dataset` 只存 `chart-series.json#series[].id` 引用，**禁止复制数值副本**。
2. **必须落 DOM 而不能写进 SVG 的文案**：来源角标、单位角标、口径说明、图注与文章底部 24px 标注带、图例文字（≤3 项）、tooltip 正文、sheet 正文、空/加载/禁用/无数据状态文字、alt/aria-label。SVG 内只允许：图表大数值（如 disc 39px 的 34.2）、8.5px `#9BA1A7` 坐标轴刻度、`role="img" aria-label`、纯图形，以及 01 §5.3 明确的 `chart-disc` 中心 13/39/11px 既有例外（保留不改，但须另配 DOM 口径副本，见 Q19）。
3. **数据文件与 `charts.mjs` 的接入边界**：`assets/data/chart-series.json` 是**唯一数值真源**；`build.mjs` 在 `expandCharts()` **之前**按 `series[].id` 把 `points / colors / segments / min / max / avg` 注入对应 `<div class="chart">` 的 `data-*`；`charts.mjs` 只负责渲染，**不得内置业务数据、不得用 `data-seed` 生成测量类图形**（`disc` 的 46 装饰点例外，须在 manifest 标注「纯装饰、无数据语义」）。禁止运行期 `fetch` / 网络请求，保持 file:// 可打开。
4. **命名与变体规则**：序列 id = `<page>-<metric>-<kind>` kebab-case；资源变体用 `--tone-mint` / `--tone-white` / `--peach` / `--mint` 后缀，不另计资源；同源复用必须严格同值：`HRV5`（3 条 line）、`HIST74`（2 张 hist）、`DOTS7x24`（1 张 dots）、`VITAL14`（5 条 line + 10 处 mini = 15 张图）。
5. **需要工程侧修正的具体点**：第 5.4 节全表；其中主理人点名的 4 处点数缺陷为 ① sleep-vitals 12→14 点、② trends 两条周折线 6→7 点、③ today HRV 5 点 vs 3 标签（口径化为「5 次采样 + 3 个时间锚点」并改正数值）、④ health 体重 spark 7→14 点。另需把 `null` 落 DOM 时转 `0` + `--faint` 色 + aria「无数据」（**不要把文本 `null` 传进 `data-values`**，`nums()` 会丢弃它并造成点数错位）。
6. **不可越界**：不改动任何截图可见文案（含 `ai-article.html` 第 2 篇末尾「（截图在此处截断…）」占位段落、`vo2max.html` 页尾截断说明、图例文字、刻度文字）；不新增页面/功能；视觉数值一律以 01 规范为准；`data-max` / `data-min` / `data-avg` / `data-ylabels` / `data-labels` 除第 5.4 节注明外保持现值。
7. **消歧不换色 / 技术边界**：`charts.mjs` 中 `greenDark` / `purpleSoft` / `ink` 与主色板的命名冲突按 01 §1.5 改名即可，**色值一律保持**，不得以「统一」为由改动任何可见颜色；全部资源仍为可内联 SVG 或纯数据，禁止 `<image>` / `<foreignObject>` / 外部 `<use href>` / 位图 / CDN / `@font-face` / `<script>` / 外部字体（01 §8-7）。
8. **01 §9 R1 裁决落地**：来源/口径文字用新增 `note-source-*` 类（≥11.5px / 400 / `--ink-2 #5C6268`），§5.4 旧字号废止；**但截图已可见的 `.update-note`（11px `#B0B6BA`）与 `.metric-note`（11.5px `--ink-3`）属只读例外，禁止「升级」改写**；`chart-disc` 中心 13/39/11px SVG 文字保留不改，另配 DOM 口径副本作为唯一口径载体；manifest 为全部 24 个资源增加 `darkVariant: reserved`，`Assets.xcassets` 仅预留 Any / Dark 槽位、不产出 `--dark` SVG、不新增深色视觉值。资源总数仍为 24 个 SVG + 14 类图表 ID，无新增文件与色值；CSS/SVG 属性改动仅 hero 的 `preserveAspectRatio="xMidYMid slice"` 一处。

## 7. 体验侧补充：任务流程 / 线框要点 / 响应式 / 无障碍

### 7.1 任务流程图（读图 → 理解口径 → 深入）

```text
进入任意含图页面
   ├─ 默认态：图卡（标题 → 大数值+单位 → 图 → 图例(≤3) → 来源角标 → 口径说明）
   │      ├─ 读图：折线/柱/环/点阵（状态色只做图形，文字另述）
   │      ├─ 点「i」→ sheet 口径说明（不新增页面）
   │      ├─ 点数据点 → tooltip（今日 HRV 08:42 24ms）
   │      └─ 点「查看报告 / 详细解读 / 了解更多」→ 下钻页或文章
   ├─ 空态：截图未覆盖的时间范围 → 文字「该时间范围未提供截图」+ 空态插画
   ├─ 无数据态：今日静息心率 / 11-08 未来日 / 时段未采样 → --faint + aria「无数据」
   ├─ 加载态：问问 AI 发送 → spinner + aria-live，随后标注 MOCK 的回复
   └─ 禁用态：边界日期 / 空输入发送 → disabled + 边界说明
降级：无 HealthKit 授权 / 无采样 → 不补 0、不留白、不画问号，只显示空态或 --faint 与文字；所有下钻保留「返回」路径（Esc / circle-btn）。
```

### 7.2 关键界面线框要点

- 图卡固定层级：① 卡片标题（+「i」说明 / PRO 徽标）→ ② 大数值 + 单位角标 → ③ 图表（内联 SVG，viewBox 320 宽）→ ④ 图例 ≤3 项 → ⑤ 来源角标 `数据来自 … · 更新于 …` → ⑥ 口径说明（≥11.5px `--ink-2`）。
- 大数值与单位相邻；「—」表示无数据，绝不用 0 替代；状态结论用文字（「状态优秀 / 注意」），颜色只作辅助。
- 文章配图：图 → 一句话图注（≤30 字）→ 底部 24px 标注带；标注带不遮挡正文，**第 2 篇末尾截断占位段落必须保持可见且原样**。
- 图表 tooltip 必须有等价的键盘可达路径（`chart-hit` 为原生 button，焦点可见），不能只靠 hover。

### 7.3 响应式策略

| 断点 | 画布 | 图表处理 | 触控 / 指针 |
|---|---|---|---|
| 桌面 ≥900px | 中间 390×844 手机画布（可切 430×932），左侧页面清单 + 右侧检查面板 | SVG `viewBox="0 0 320 h"` 宽度 100% 自适应，不横向滚动 | 指针 hover 显示 tooltip；点击等价触发 |

### 7.4 无障碍清单（Nielsen 启发式 + WCAG 对齐）

- [x] **系统状态可见**：每张图都有来源角标与更新时间；空/加载/禁用/无数据四态各有明确文字（不只是图形）。
- [x] **对比度**：单位/口径/来源 ≥11.5px `--ink-2 #5C6268`（6.17:1）；8.5px `#9BA1A7` 仅坐标轴刻度；四档状态色不用于文字。
- [x] **读屏**：每个 SVG `role="img" aria-label` 按 01 §6.4 填实（50 条图表 + 24 资源 + 9 文章图）；装饰层 `aria-hidden="true"`；空点 aria 注明「无采样」。
- [x] **键盘 / 焦点顺序**：标题 → 大数值 → 图 → 图例 → 来源角标 → 说明按钮 → 下钻按钮；原生 button/input/select；Esc 关闭 sheet / 返回今日。
- [x] **不只靠颜色**：状态同时有文字（「状态优秀 / 注意 / 无数据」）与图形；点阵编码 0–4 在 aria 与图例中有文字映射。
- [x] **防错 / 可逆**：缺失不补值；边界日期禁用并说明；下钻都有返回；无破坏性操作。
- [x] **一致性**：50 条序列同字段、同来源措辞、同更新时间口径；同源序列严格同值。
- [x] **图例 ≤3 项**，超出改 sheet（本版最多 3 项）。
- [x] **动效降级**：`prefers-reduced-motion` 时禁用 spinner 以外的过渡；图表为构建期静态 SVG，无运行期动画依赖。

### 7.5 高风险交互与降级方案
